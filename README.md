# Web Snake Game 🐍

A modern implementation of the classic Snake Game built with React, TypeScript, and Tailwind CSS.

## ✨ Features

- **Classic Snake Gameplay**: Control the snake to eat food and grow longer
- **Power-ups System**: 
  - 🚀 Speed Boost: Move faster for a limited time
  - 🏆 Points Multiplier: Double points for a limited duration
- **Combo System**: Chain multiple food items for combo points
- **Responsive Design**: Play on desktop or mobile devices
- **Modern UI**: Clean interface with visual feedback and animations
- **High Score Tracking**: Compete with yourself to beat your best score

## 🎲 How to Play

- Use **arrow keys** or the **on-screen buttons** to change the snake's direction
- Press **spacebar** or the **play/pause button** to start/pause the game
- Collect **red food** to grow and earn points
- Pick up **special power-ups** for temporary advantages:
  - **Blue power-ups**: Increase your speed
  - **Yellow power-ups**: Double your points
- Avoid hitting the snake's body
- Try to achieve the highest score possible!

## 💻 Installation & Setup

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/your-username/web-snake-game.git

# Navigate to project directory
cd web-snake-game

# Install dependencies
npm install

# Start development server
npm run dev
```

The game should now be running on `http://localhost:5173/`

## 🚀 Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
